## **CI/CD Testing Demo (PyTest + Selenium)**

### 📌 **Overview**

This repository demonstrates **continuous testing** using **PyTest** and **Selenium** with an automated **CI/CD pipeline** in **GitHub Actions**. The goal is to run automated tests (unit + UI) on every push or pull request, generate test reports, and deploy them to **GitHub Pages** for easy access.

### ⚙️ **Tech Stack**

* **PyTest** → for running unit tests and Selenium-based browser tests.
* **Selenium** → for browser automation (Google Chrome).
* **GitHub Actions** → for automating the CI/CD pipeline.
* **Chromedriver + Google Chrome** → for browser-based tests.
* **JUnit + HTML Reports** → for test result generation.

---

### 🚀 **Features**

* **Unit tests**: Basic sanity checks to ensure that your core logic works as expected.
* **Selenium UI tests**: Automated browser tests to ensure your web application behaves correctly.
* **Test Report Generation**:

  * **JUnit XML** report generated by **PyTest**.
  * **HTML** report generated using **junit2html**.
  * **Reports uploaded as GitHub artifacts** after each test run.
* **CI/CD Pipeline**:

  * Automatically runs **tests** on **every push** and **pull request**.
  * Deploys test reports to **GitHub Pages** for easy access.

### 🛠️ **Setup & Run Locally**

1. **Clone the repository:**

   ```bash
   git clone https://github.com/hasanulkabir-md/ci-cd-testing-demo.git
   cd ci-cd-testing-demo
   ```

2. **Create and activate a virtual environment:**

   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Linux
   ```

3. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Run the tests locally:**

   ```bash
   pytest --junitxml=report.xml
   python -m junit2html report.xml report.html
   ```

5. **Open the report:**

   ```bash
   xdg-open report.html  # Linux
   open report.html      # macOS
   ```

---

### 🏃 **CI/CD Pipeline with GitHub Actions**

The **CI/CD pipeline** is defined in `.github/workflows/ci.yml`. It automatically:

1. **Installs dependencies** (`pytest`, `selenium`, etc.).
2. **Runs tests** using **PyTest** with **JUnit XML** output.
3. Converts the **JUnit XML** output to an **HTML report** using `junit2html`.
4. **Uploads the test report** as an artifact in the GitHub Actions UI.
5. **Deploys the test report** to **GitHub Pages** for easy access via URL.

---

### 📊 **Test Reports**

* After every **push** or **pull request**, GitHub Actions will run tests and produce a test report (`report.html`).
